2. Що реалізовано
Ліміт: розрахунок не списується, якщо його не виконано — порожня фігура, ліміт вичерпано або ті самі дані вдруге.
Refund, chargeback, disputed і вимкнений у Gumroad ключ — Pro вимикається одразу при перевірці.
Недоступний Gumroad: Pro лишається до 7 днів від останньої успішної перевірки.
Зміна дати в системі: якщо годинник відвели назад більш ніж на добу, кешу не довіряємо й перевіряємо ліцензію знову.
Ключ: зберігається повністю (без нього не буде повторної перевірки), а в UI видно тільки ****-****-XXXX.
Мова: тексти про оплату й ліцензію тільки англійською, як у ТЗ.

5–6. Serverless і змінні оточення
Serverless endpoint не потрібен. За документацією Gumroad, POST /v2/licenses/verify — єдиний endpoint, якому не потрібна реєстрація OAuth. product_id не є секретом. Змінних оточення немає. Пошук access_token|secret|bearer|client_id у extension/ нічого не знайшов (лише коментар).

7. Як протестувати Free
Load unpacked → Calculate → бейдж Free · 1/50.
У DevTools попапу: chrome.storage.local.set({usage:{count:49,month:'2026-09'}}), перевідкрити → Calculate дає 50/50 → наступний Calculate блокується і показує вікно ліміту.
Поставити month:'2026-08' → лічильник 0/50.
Змінити поля, мову, одиниці, перевідкрити попап → лічильник не змінюється.
8–9. Як протестувати Pro і шлях покупка → ліцензія → активація
Створити промокод на 100% і «купити» продукт.
Взяти ключ із листа-чека, вставити в поле → Activate → ✓ Pro · Lifetime, розрахунки без ліміту.
Перезапустити браузер → Pro лишається.
DevTools → Network → Offline → Refresh License → Pro лишається.
Зробити refund у Gumroad → Refresh License → «This license is no longer active.»
